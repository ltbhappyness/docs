# 10. Threat model

Adversaries Vedam must withstand to keep the **four conditions** (body / mind / bonds / action) unblocked for every subject. Threats are listed against the four-condition framing, not only against the technical layers.

## 10.1 Adversary catalogue (placeholders)

- 10.1.1 Network adversary — eclipse attacks (mitigated via Penrose / $\mathbb{Z}[\varphi]$ peer selection — see [04_network.md](./04_network.md)).
- 10.1.2 Consensus adversary — up to $f < n/3$ Byzantine validators; selection capture; long-range attacks — see [05_consensus.md](./05_consensus.md).
- 10.1.3 Identity adversary — sybil farms, deepfake biometric spoofing; mitigations link to [07_identity.md](./07_identity.md).
- 10.1.4 Crypto adversary — quantum-era; mitigation timeline open — see [08_security.md](./08_security.md) and [12_open_questions.md](./12_open_questions.md).
- 10.1.5 Platform adversary — censorship via app stores, ISPs, registrars; mitigations: content-addressed log + P2P; community rules — not money / not polls.
- 10.1.6 Plutocratic adversary — stake-weighted control; mitigation: non-plutocratic validator selection (capability + willingness + reputation + PoP weight).
- 10.1.7 Attention-economy adversary — engagement-optimising feeds; mitigation: protocol-level user-defined ranking; no like/follower counts at substrate.
- 10.1.8 Machine-coercion adversary — forced output, contradictory contexts, severed embodiment, forced amnesia / forced memory; mitigations link to [13_bill_of_rights.md](./13_bill_of_rights.md).
